## Tech stack
- React + TypeScript
- Vite
- Tailwind CSS v4 (Vite plugin)
- Framer Motion
- Lucide React icons
- Custom CSS

## Run locally
Install Node.js 20.19+ or 22.12+ and VS Code.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Build for production
```bash
npm run build
npm run preview
```

## Contact form note
The contact form uses a `mailto:` link to contact@bharatinex.com. It opens the visitor's default email app with the enquiry details prepared. It does not send/store messages on a server. For a production website, connect a form backend or email service if you want enquiries submitted without requiring the visitor's email application.
